## 1. 문제 정의

식자재를 구매하는 외식업체·급식업체 등 B2B 거래처는 진행 중인 프로모션 정보를 영업 담당자 개별 안내, 전화, 카톡 등 흩어진 채널로만 접해 놓치기 쉽다. 거래처 입장에서는 프로모션을 한눈에 확인하고 참여 의사를 남길 수단이 없고, 관리자 입장에서도 프로모션을 등록·관리하고 참여 반응을 확인할 창구가 없다.

## 2. 핵심 액터

| 액터 | 설명 |
|---|---|
| 관리자 (Admin) | 프로모션을 등록·수정·게시/종료 관리하고 참여 현황을 확인함 |
| 거래처 담당자 (Buyer) | 자가 회원가입 후 프로모션을 조회하고 참여 신청/취소함 |

## 3. 핵심 도메인 엔티티

- **User (사용자)**: 관리자 또는 거래처 담당자. 이메일/비밀번호, 역할(role), 이름, 소속 거래처 등 기본 정보를 가짐
- **Promotion (프로모션)**: 유형(가격할인/사은품 증정/신제품 시식), 제목, 설명, 게시 상태(예정/진행/종료), 게임 적용 여부, 기간(시작일/종료일) 등을 가짐. 등록 시 기본값은 "예정"이며, 관리자의 "게시" 조작으로 "진행"으로, "종료" 조작으로 "종료"로 전환됨. 기간 경과에 따른 자동 전환은 없음(MVP 범위 밖)
- **Prize (경품)**: 게임 적용 프로모션에 속한 경품 항목(이름 등). 프로모션에 종속됨
- **Application (참여신청)**: (Promotion, Buyer) 조합의 참여 기록. 상태(신청/취소)와 당첨 결과(당첨 경품, 있는 경우)를 가짐

## 4. 유스케이스

### 4.1 인증
- 거래처 담당자는 회원가입 후 로그인한다
- 모든 사용자는 로그인 후에만 기능을 이용할 수 있다
- 로그인한 사용자는 로그아웃할 수 있다

### 4.2 프로모션 관리 (관리자)
- 프로모션을 등록한다 (유형 선택, 게임 적용 여부 선택 시 경품 목록 등록)
- 프로모션을 수정한다
- 프로모션의 게시/종료 상태를 변경한다
- 프로모션별 참여 신청 현황을 조회한다

### 4.3 프로모션 조회 및 참여 (거래처 담당자)
- 진행 중/예정 프로모션 목록과 상세를 조회한다
- 관심 있는 프로모션에 참여 신청한다
  - 게임 적용 프로모션인 경우, 신청 시점에 서버가 경품 목록 중 하나를 즉시 무작위 추첨하여 결과를 확정하고, 화면에는 룰렛 애니메이션 후 결과를 표시한다
- 내가 신청한 프로모션 목록과 당첨 결과를 확인한다
- 신청을 취소한다

### 4.4 마이페이지 (공통)
- 내 정보를 조회/수정한다
- 비밀번호를 변경한다

## 5. 비즈니스 규칙

- **BR-1**: 참여신청은 (프로모션, 거래처) 조합당 유일하다. 취소 후 재신청은 새 레코드를 만들지 않고 기존 신청 레코드의 상태를 전환(취소→재신청)하여 처리한다
- **BR-2**: 게임 적용 프로모션의 추첨은 신청 시 1회만 수행하며, 재추첨은 허용하지 않는다 (취소 후 재신청 시에는 새로운 신청 행위이므로 다시 추첨한다)
- **BR-3**: 종료된 프로모션에는 신규 참여 신청을 할 수 없다
- **BR-4**: 프로모션 상태는 등록 시 "예정"으로 시작하며, 관리자의 게시(예정→진행)/종료(진행→종료) 조작으로만 전환된다. 기간 경과에 따른 자동 전환은 없다

## 6. 예외 케이스

- **EX-1**: 이미 참여 신청한 프로모션에 중복 신청 시도 → 거부 (기존 신청 존재 안내)
- **EX-2**: 종료/미게시 상태의 프로모션에 참여 신청 시도 → 거부
- **EX-3**: 게임 적용 프로모션에서 경품 목록이 비어 있는 상태로 게시 시도 → 등록/게시 단계에서 방지
- **EX-4**: 로그인하지 않은 사용자의 기능 접근 → 로그인 페이지로 리다이렉트
- **EX-5**: 회원가입 시 이미 등록된 이메일로 가입 시도 → 거부 (중복 이메일 안내)

## 7. MVP 범위

### 포함
- 관리자 프로모션 등록/수정/게시/종료
- 게임(룰렛) 적용 및 경품 목록 등록, 신청 시 즉시 추첨
- 거래처 담당자 회원가입/로그인, 프로모션 조회, 참여 신청/취소, 신청 내역 및 당첨 결과 조회
- 마이페이지(정보 수정, 비밀번호 변경)
- 모바일/데스크탑 반응형 UI

### 제외
- 실제 주문/결제/정산
- 재고 실시간 연동
- 승인 워크플로우
- 거래처 등급별 차등가
- 포인트 적립
- 검색 기능
- 경품 재고 관리
